## How to read this

### Measured work

- 682 older merged PRs were scanned. 178 had usable, focused task records. They are combined with the earlier 33-PR sample, for 211 unique PRs across 206 tasks.
- Branches and saved PR links join T3 Code threads to merged GitHub diffs. Shared tasks are grouped. Usage runs from task start through the final merge.
- Usage comes from native Claude and Codex records plus session- or response-matched provider captures. Repeated response records are counted once. Cache reads, cache writes, and output remain separate.
- Code + config excludes tests, fixtures, generated files, and prose, using T3 Code's own path classifier. A truncated file list is excluded from that view.
- The test purge, reverts, broad maintenance work, and records with unresolved usage or prices are excluded. Empty or missing usage is never treated as zero.

### Limits that matter

- This is an observed sample, not an exhaustive accounting of every attempt. It includes matched takeovers and reviews, but cannot prove all prior work was recovered.
- Fable 5 mainly appears in July–August, Fable 5.1 in September, and Opus 5.5 in October. Task mix, instructions, software, and workflow changed over time.
- GPT-6 Astra has only eight retained tasks and GPT-6.1 Sol has only three predominantly single-model tasks. Do not infer a model ranking from those samples.
- The price calculation uses today's standard token rates for consistent comparison. It is not a historical invoice or a subscription bill. Fast/priority premiums, tool charges, and external review-bot costs are not included.
- “Tokens” includes repeated cached context. “Fresh tokens” means uncached input + cache writes + output; it still includes reasoning and tool context, not just code generated.
